# Trinetra Fleet Solutions Static Website

Plain HTML/CSS/JavaScript website with minimal PHP form handlers. No Laravel, Next.js, React, Composer, database, login, dashboard or build process is required on Hostinger.

Upload the contents of this folder directly to public_html. Copy config/mail-config.example.php to config/mail-config.php on the server and set SMTP/password details if needed. The committed handler uses PHP mail() for maximum shared-hosting compatibility.
